
# Mario com Nariz

Utilize seu nariz para movimentar o Mario e tente alcançar o maior número de pontos!

Requer webcam. Projeto para fins educativos/didáticos.


## Funcionalidades

- Utilize de seu nariz para mover o Mario.
- Mario irá se movimentar para a esquerda ou direita dependendo da posição do nariz na webcam.
- Para pular, mova o nariz para cima.
- Caso preciso, utilize as instruções no topo da página.


## Stack utilizada

- **Front-end:** HTML, CSS, Javascript e ml5.js.
